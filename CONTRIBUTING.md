# Contributing

Useful contributions: protocol tests, synthetic fixtures, cross-platform fixes, and hardware notes backed by official sources.

Keep the lab standalone. Use generated audio only. Do not add product code, recordings, transcripts, account data, credentials, model weights, vendor binaries, or private deployment links.

Run `python -m unittest discover -s tests -v` before sending a pull request. Describe simulated checks separately from physical hardware checks. Contributions use this directory's MIT license; upstream material keeps its own terms.

Open changes at [rodneyg/phantom-audio-lab](https://github.com/rodneyg/phantom-audio-lab/pulls). A maintainer reviews public contributions. There is no automatic sync into the private product and no access to its source or data.
